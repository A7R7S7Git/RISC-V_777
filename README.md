Малиновский А.Ф., 126 группа, 11 в списке
# Запуск практической работы в RARS

Группа **126**, номер в списке **11**. Параметры уже установлены в программах.

1. Установите **Java 8 или новее** и скачайте `rars1_6.jar` из раздела Assets на [странице RARS 1.6](https://github.com/TheThirdOne/rars/releases/tag/v1.6).
2. Откройте терминал в папке с RARS и выполните:

   ```text
   java -jar rars1_6.jar
   ```

3. В меню **Settings** включите `Permit extended (pseudo) instructions and formats`. Отключите `Assemble all files in directory` и `Assemble all files currently open`. Используйте режим **RV32**.
4. Через **File → Open** откройте одну программу:
   - `task_a.asm` — сравнение введённого числа с 11;
   - `task_b.asm` — вывод диапазона с шагом 11;
   - `task_c.asm` — заполнение массива на 27 чисел.
5. Нажмите **Run → Assemble**, затем **Run → Go**.
6. В области **Run I/O** вводите целые числа, подтверждая каждое клавишей **Enter**. Программы «а» и «б» ожидают одно число. В программе «в» ввод завершится после 27 чисел или при вводе `0`; завершающий ноль не сохраняется.
7. Для повторного запуска выберите **Run → Reset**, затем **Run → Go**. После изменения кода сохраните файл и снова выполните **Assemble**.

**Запускайте файлы по отдельности.** После запуска программа сразу ожидает ввод, даже если приглашение не отображается.
